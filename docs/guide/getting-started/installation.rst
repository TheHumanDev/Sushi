Installation
==================

There are two ways to install Sushi:

1. Install the Visual Studio Code extension from the Github Repository: `Latest Release <https://github.com/TheHumanDev/Sushi/releases/latest>`__

2. Install the Visual Studio Code extension from the marketplace: `Marketplace <https://marketplace.visualstudio.com/items?itemName=TheHumanDev.sushi-language>`__

Using a Language Server (LSP)
------------------------------

The Sushi Language extension comes out-of-the-box with both a language server and a compiler,
which are both contained in Sushi.exe. No additional setup is required on the developer's
part once the .vsix is installed.

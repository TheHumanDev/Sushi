Sushi Programming Language
===================================
Welcome to the official documentation for Sushi.

**Sushi** is an experimental, strongly typed systems programming language focused on memory safety, predictable behavior, and providing low-level control without unnecessary complexity.
This documentation will grow alongside the compiler as features come online and design decisions are made. This will also be the home for the authoritative Sushi Language Specification.

Licensing
